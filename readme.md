# Dainty – Panda Theme

Twenty-five variations of [Panda Syntax](https://github.com/tinkertrain/panda-syntax-vscode), each with slightly different chroma and lightness.

## Por que?

I personally got attached to this version, its been removed from the Cursor extension marketplace, and Alexander Teinum's repo is gone.

## Install

You need the `.vsix` file in this repo. Grab it two ways:

**Download the repo** as a ZIP from the green "Code" button above, then unzip it. Or clone it:

```sh
git clone https://github.com/seafarer/dainty-panda-theme-vscode.git
```

Then install the theme. Pick whichever is easier.

### From inside Cursor

1. Open the Extensions panel (`Cmd+Shift+X` on Mac, `Ctrl+Shift+X` on Windows and Linux)
2. Click the `…` menu at the top of the panel
3. Choose **Install from VSIX…**
4. Pick `releases/dainty-panda-theme-vscode-1.0.2-local.1.vsix`
5. Reload when it asks

### From the terminal

```sh
cursor --install-extension releases/dainty-panda-theme-vscode-1.0.2-local.1.vsix
```

Swap `cursor` for `code` if you're on VS Code.

### Turn it on

Press `Cmd+Shift+P` (or `Ctrl+Shift+P`), type "color theme", hit Enter, and pick any of the Dainty Panda variations from the list.

Higher chroma means more colorful. Higher lightness means a lighter background.
